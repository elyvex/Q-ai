| row actions → clipboard | references and rows leave the page as text |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-14-63 | Tampering | table/detail rendering | medium | mitigate | Every cell is a React text child; unknown payload fields render as label/value text, never as markup; `layer_separation` rejects HTML injection |
| T-14-64 | Spoofing | sorting/ordering claims | low | mitigate | Each view states whether order is engine order or user-sorted, so a re-sorted list is never presented as service ranking |
| T-14-65 | Info disclosure | row copy / export | low | accept | Copy actions place already-rendered values into the clipboard; no additional request is made |
| T-14-66 | Denial of service | client pagination | low | accept | Paging and sorting are pure functions over already-fetched rows and add no network traffic |
| T-14-SC | Tampering | web dependencies | low | accept | No package added; `npm test`, `npm run build` and `layer_separation` gate the change |
