    Create a tafsir search service that reuses the Phase 3 normalization infrastructure. No new normalization rules.

    **Migration 0029 — tafsir_search_forms:** Derived search forms table with `tafsir_id` (FK → tafsir_records ON DELETE CASCADE), `form_type` (CHECK: 'exact' | 'normalized' | 'skeleton'), `form_text`, `profile_id`, `profile_version`, `corpus_generation`, PRIMARY KEY (tafsir_id, form_type, profile_id, profile_version). FTS5 virtual table `tafsir_fts` over (content_text, author, verse_reference) with content='tafsir_search_forms'.

    **Search service:** `TafsirSearchService` with method `search(query: &str, profile: NormalizationProfile) -> Result<Vec<TafsirSearchResult>, SearchError>`. The service:
    1. Normalizes the query using `quran_normalization::NormalizationPipeline`
    2. Queries the FTS5 index for matches
    3. Returns results with work name, author, dimensions, and a text snippet
    4. Never mutates canonical text

    Follow the `quran_forms.rs` pattern: derive search forms at ingest time into `tafsir_search_forms`, never write normalized text into `tafsir_records.text`.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI/API → Application | User input crosses into search/tool layer |
| Application → Storage | Database queries with user-influenced parameters |
| Normalization → Canonical text | Search forms derived from canonical text must never mutate it |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-05 | Tampering | tafsir_search_forms | high | mitigate | Canonical text is immutable; search forms are derived into separate table. No write path from search to tafsir_records.text. |
| T-06-06 | Tampering | tafsir_records | medium | mitigate | text column is canonical-only. Derived search forms go into tafsir_search_forms with corpus_generation stamp. |
| T-06-07 | Repudiation | tafsir tools | medium | mitigate | Every tool result carries research_checksum + ReproducibilityData. Canonical references are fully qualified. |
</threat_model>
