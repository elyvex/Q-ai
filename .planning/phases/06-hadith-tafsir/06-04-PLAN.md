  <name>Task 1: Hadith/tafsir ingestion pipeline</name>
  <files>

    crates/hadith-ingestion/src/validate.rs

  <action>
    Implement the hadith/tafsir ingestion pipeline following the Phase 2 `sources` + `quran-corpus` staging pattern.

    **Parser:** `HadithParser` trait with method `parse(input: &str) -> Result<Vec<ParsedHadith>, ParseError>`. Provide a JSON parser implementation that reads a common hadith JSON format (collection name, source number, matn text, optional isnad text, optional narrator names). The parser preserves source numbering verbatim.

    **Validator:** `HadithValidator` with method `validate(hadith: &ParsedHadith) -> Result<(), ValidationError>`. Validation rules:
    - source_number is non-empty
    - matn_text is non-empty
    - collection exists in hadith_collections
    - grading records have non-empty scholar_name and source_citation
    - No consensus-merged grading values (reject any input containing a "consensus" or "majority" grading field)

    **Pipeline:** `IngestionPipeline` with methods following the `SourceState` workflow:
    - `discover(source_url) -> Source` — register the source in the catalog
    - `stage(source_id, data) -> Vec<StagedRecord>` — parse and validate, write to staging tables
    - `validate(source_id) -> ValidationReport` — run all validation rules
    - `activate(source_id) -> Result<(), ActivationError>` — atomically move from staging to active tables

    Per D-01 (locked): source numbering preserved verbatim. Per D-02 (locked): matn_text is canonical-only. Per D-03 (locked): no consensus-merged gradings.
  </action>
  <verify>
    <automated>cargo test -p hadith-ingestion</automated>
  </verify>
  <done>
    - JSON parser reads hadith records with collection, source_number, matn, isnad
    - Validator rejects empty source_number, empty matn, missing collection
    - Validator rejects any input with consensus-merged grading fields
    - Pipeline discover → stage → validate → activate workflow completes
    - Staged records are atomically activated
    - Source numbering is preserved verbatim through the pipeline
  </done>
</task>
