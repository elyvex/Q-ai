<task type="auto">
  <name>Task 2: Computational matching + owner gate</name>
  <files>
    crates/application/src/verse_link.rs
    crates/application/src/lib.rs
  </files>
  <action>
    Implement the verse linking service with computational matching and owner gate.

    **Computational matching:** `VerseLinkService` with method `suggest_links(source_type, source_id) -> Vec<VerseLink>`. The service:
    1. Extracts Arabic phrases from the hadith/tafsir text
    2. Normalizes using `quran_normalization::NormalizationPipeline`
    3. Matches against normalized Quran text using FTS5
    4. Scores each match based on phrase length and context overlap
    5. Creates VerseLink records with `label = Uncertain`, `confidence = score`
    6. Stores algorithm name and version for reproducibility

    **Owner gate:** Method `confirm_link(link_id, reviewer) -> Result<(), LinkError>` and `reject_link(link_id, reviewer) -> Result<(), LinkError>`. These methods:
    1. Require reviewer name (non-empty)
    2. Set `label = Confirmed` or `Rejected`
    3. Set `decided_at` timestamp
    4. Record the reviewer in the audit trail

    **Read path enforcement:** Method `get_links_for_verse(surah, ayah, include_uncertain: bool) -> Vec<VerseLink>`. When `include_uncertain` is false (default), only `Confirmed` links are returned. When true, all links are returned with their labels visible.

    Per D-07 (locked): the read path filters on `label = 'confirmed'` for authoritative display. Computational links are always labeled and gated.
  </action>
  <verify>
    <automated>cargo test -p application -- verse_link</automated>
  </verify>
  <done>
    - Computational matching creates verse links with confidence scores
    - All new links start with label=Uncertain
    - Owner can confirm or reject links with reviewer name + timestamp
    - Read path with include_uncertain=false returns only confirmed links
    - Read path with include_uncertain=true returns all links with labels
    - Confidence thresholds are applied: high (>0.9), medium (0.7-0.9), low (<0.7)
  </done>
</task>

| Computational → Verse links | Algorithmic suggestions cross into the link store |
| Owner → Verse links | Human confirmation crosses into authoritative status |
| Data layer → UI | Grading assembly must not resolve disagreement |

| T-06-09 | Repudiation | grading disagreement | high | mitigate | Per-scholar independent records. No consensus field. Assembly shows all gradings side-by-side. Data layer never resolves disagreement. |
