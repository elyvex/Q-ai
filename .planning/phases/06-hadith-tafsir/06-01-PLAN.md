<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI/API → Application | User input crosses into search/tool layer |
| Application → Storage | Database queries with user-influenced parameters |
| Normalization → Canonical text | Search forms derived from canonical text must never mutate it |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-01 | Tampering | hadith_search_forms | high | mitigate | Canonical text is immutable; search forms are derived into separate table with corpus_generation stamp. No write path from search to hadith_records.matn_text. |
| T-06-02 | Spoofing | hadith_gradings | high | mitigate | Per-scholar independent records with source_citation required. No consensus field exists. Grading attribution is always shown. |
| T-06-03 | Tampering | hadith_records source_number | medium | mitigate | source_number is NOT NULL, preserved verbatim. Internal id is for DB relationships only. Citations reference source_number. |
| T-06-04 | Repudiation | hadith tools | medium | mitigate | Every tool result carries research_checksum + ReproducibilityData. Canonical references are fully qualified. |
| T-06-SC | Tampering | cargo installs | high | mitigate | No new external dependencies. All crates already in workspace. |
</threat_model>
