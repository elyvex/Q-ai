## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| workspace crate graph | A new crate/dependency edge can circumvent the enforced layering if the allowlist is not updated fail-closed |
| dataset text → terminal | Untrusted dataset strings rendered by ratatui can inject terminal control sequences |
| interactive process → terminal state | A panic mid-render can leave the terminal in raw mode |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-04 | Tampering | `crates/tui` → application edge | high | mitigate | `[tui]` allowlist entry added with the dependency in the same commit; `xtask arch-check` fails closed on any unlisted edge (Pitfall 2). |
| T-05-05 | Tampering | terminal escape injection (dataset text) | medium | mitigate | `sanitize_terminal_text` strips C0/C1/ESC before any ratatui render; unit-tested. |
| T-05-06 | Denial of Service | interrupted/panicking TUI leaves terminal raw | low | mitigate | Panic hook calls `ratatui::restore()` before delegating; `^C`/`q`/`Esc` handled in the event loop. |
| T-05-SC | Tampering | cargo installs (ratatui/crossterm) | low | accept | Packages are `OK` in the RESEARCH legitimacy audit (crates.io, high downloads, known repos); pinned exact versions. |
