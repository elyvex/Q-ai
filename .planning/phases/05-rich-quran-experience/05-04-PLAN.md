<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → axum router | Client-controlled paths hit the static fallback; a mis-ordered fallback could swallow `/api/*` |
| compile time → embedded assets | A missing `web/dist` or a committed build artifact changes the release shape |
| SPA → network | Any external reference breaks the offline/deny-egress constraint |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-09 | Information Disclosure | static-asset path traversal | high | mitigate | Use `rust-embed::get` only (resolves embedded relative paths); never join user input onto a filesystem root; fallback 404s unknown `/api/*`. |
| T-05-10 | Tampering | SPA fallback swallowing API routes | high | mitigate | `.fallback` registered after all API/health routes and explicitly 404s `api/*`/`health*`; router test locks the ordering. |
| T-05-11 | Information Disclosure | runtime egress (CDN/fonts) | medium | mitigate | No external URLs; system Arabic font stack default; OD-04 gate; source scan in plan 05-07. |
| T-05-SC | Tampering | npm installs (react/vite) | high | mitigate | Blocking human checkpoint confirms pinned versions against npmjs.com before `npm install`; exact pins (no `^`). |
</threat_model>
