<objective>
Deliver the phase's operator-visible surfaces (criteria 2 and 3, D-10/D-11) and close the largest demonstrated gaps in the register: the reference-comparison family is exercised only from Rust tests because the production path hardcodes `ImportOptions::default()` and the doctor check is a hardcoded warn (QC-03, QC-10, Pitfall 3), and the identity/primary/license values persisted in plan 02-01 have no CLI proof.

Task ledger: `TASK-002-canonical-quran-core` (see `docs/04-tasks/`) — this plan is one implementation unit of that phase task.

Purpose: "Corpus integrity checks pass" is only meaningful if an operator can reproduce the check and the reference family is honestly classified; today the only production path can never evaluate QV-015 and the operator surface cannot distinguish a skipped family from a passed one. Criterion 2 likewise needs the stored hash and pinned reference visible on the command output, not only in library tests.
Output: `qai quran verify`, a state-derived reference check, real QV-015 evaluation through the operator import path, a typed per-difference classification in the QV-015 report, the stored hash on the lookup line, and the identity/primary/license CLI snapshot.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator CLI → read-only DB handle | `qai quran verify` must not acquire a write path; it reads canonical rows, validation reports, and the active pointer. |
| operator-supplied reference manifest → importer | The reference is untrusted input crossing into the pipeline; it is parsed by the existing adapter and compared byte-for-byte, fail-closed. |
| import run → staging → canonical | QV-015 Fatal aborts before staging; nothing in this plan touches the approval-gated publication boundary. |
| persisted validation report → operator output | The six-family classification is derived from stored findings; a fabricated classification would misrepresent integrity evidence. |
| canonical row → operator CLI output | The identity/primary/license values are rendered to the operator; a fabricated value here would misrepresent provenance. |
