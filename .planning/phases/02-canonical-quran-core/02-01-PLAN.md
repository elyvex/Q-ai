## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| manifest bytes → importer | Untrusted operator-supplied JSON crosses here; every value is parsed into a typed intermediate format before any storage write. |
| staging (`quran_stg_*`) → canonical (`quran_*`) | The only canonical-write boundary; crossed solely inside one approval-gated `UnitOfWork` in `activate_edition`. |
| canonical row → operator CLI output | Canonical identity/license values are rendered to the operator; a fabricated value here would misrepresent provenance. |
