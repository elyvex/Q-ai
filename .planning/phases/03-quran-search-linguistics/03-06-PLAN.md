<objective>
Implement the D-07 machine-readable license/attribution matrix and the activation-rejection gate so no dataset can be activated without verified license evidence.

Purpose: 03-RESEARCH.md Pitfall 2 and G-04 found `licenses/README.md` reads like a gate but no code path consults it: `activate_morphology` promotes rows on approval + findings + alignment alone, and the CLI records `license_status: \"Unspecified\"`. This is both a legal and a safety control (preventing activation of a dataset with unknown provenance). This plan adds a pure validation module, the gate in the activation path, CLI plumbing, a machine-readable matrix, and fail-closed tests.
Output: `crates/quran-morphology/src/license.rs`, the activation gate, CLI license flags, `fixtures/quran/morphology/license-matrix.json`, and license-gate tests.
</objective>
