<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted query text → normalization + FTS | CLI arg / test input crosses into the shared normalization pipeline and indexed search |
| canonical tables → derived index | read-only derive; must never write back |
| derived index → result contract | a hit is only valid if it carries trace + canonical span + verified quotation |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | normalized search query binding | high | mitigate | Query text is normalized then bound as an FTS term/substring; filters stay typed. The new test asserts empty input is a typed error, never an all-match or panic. |
| T-03-02 | Tampering | displayed canonical text | critical | mitigate | Per-hit byte-identity test (SC5) + MV-018 canonical-unchanged post-check in the rebuild path. |
| T-03-03 | Spoofing | result without verified quotation | high | mitigate | Only the validating `SearchHit` constructor is used; no new result type bypasses canonical quotation + span + trace. |
| T-03-04 | Denial of Service | unbounded result sets | medium | mitigate | `limit` stays clamped `1..=1000`; the tracer uses the existing clamped path. |
| T-03-05 | Repudiation | heuristic match presented as exact | medium | mitigate | Trace is mandatory on every hit; tests assert non-empty `explanation`. |
| T-03-SC | Tampering | cargo/npm installs | high | accept | No new packages are proposed by 03-RESEARCH.md; all changes close inside existing workspace crates with `Cargo.lock`-pinned deps. `cargo run -q -p xtask -- arch-check` remains the edge gate. |
</threat_model>
