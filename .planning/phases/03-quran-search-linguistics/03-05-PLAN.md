<threat_model>
**Posture:** ASVS Level 1; any unmitigated `high`-severity threat blocks this plan — no auto-approval.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP body → lexicon backend | untrusted kind/id/root/lemma strings cross into SQL-bound lookups |
| backend → HTTP response | lexicon results must carry attribution and CountingRules, never bare data |
| AppState wiring → routes | the new backend must sit behind the same layers (body limit, timeout, concurrency) as search |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-18 | Tampering | lexicon route input binding | high | mitigate | Non-empty validation + typed args; storage lookups are bound parameters; no string-concatenated SQL or paths. |
| T-03-19 | Information disclosure | unattributed lexicon result | medium | mitigate | Handlers include dataset id/attribution; contract test asserts attribution on the active-dataset path. |
| T-03-20 | Denial of Service | new routes without the shared layers | medium | mitigate | Routes are registered on the same router whose layers already enforce a 1 MiB body limit, 30 s timeout, and concurrency 128. |
| T-03-21 | Spoofing | empty 200 for unavailable capability | high | mitigate | No-dataset path maps the typed `UnavailableDataset` to an error status; contract test pins it. |
| T-03-SC | Tampering | cargo/npm installs | high | accept | No new packages; the backend reuses `axum`, `serde`, and existing application crates. |
</threat_model>
