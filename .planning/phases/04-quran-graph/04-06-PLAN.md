## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| request selector → projection family read | A caller-supplied family string crosses into which build is read; it must select, never widen, visibility. |
| default scope → concept/entity material | Concept and entity nodes carry pending attribution; a selector must never upgrade their status or leak restricted material. |
| annotated build → read surfaces | The seed-published concept edges cross into CLI/HTTP/tool output through the same policy filter as any export. |
