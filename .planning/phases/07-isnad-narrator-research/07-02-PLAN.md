  <name>Task 1: Create isnad CLI module</name>
  <files>
    crates/cli/src/isnad.rs
  </files>
  <action>
    Create `crates/cli/src/isnad.rs` mirroring `crates/cli/src/hadith.rs` and `links.rs`.

    Define `IsnadAction` clap Subcommand enum:
    - `Narrator { #[arg(long)] id: String }`
    - `Rijal { #[arg(long)] id: String }`
    - `Trace { #[arg(long)] from: String, #[arg(long)] to: String, #[arg(long, default_value_t = 3)] k: usize }`
    - `Identity { #[command(subcommand)] action: IdentityAction }` where `IdentityAction` = `Propose { #[arg(long)] claim: String, #[arg(long)] evidence: String, #[arg(long)] source_location: Option<String>, #[arg(long)] provenance_layer: String, #[arg(long)] algorithm: Option<String>, #[arg(long)] algorithm_version: Option<String>, #[arg(long)] confidence: Option<f64> }`, `Accept { #[arg(long)] id: String, #[arg(long)] reviewer: String }`, `Reject { #[arg(long)] id: String, #[arg(long)] reviewer: String, #[arg(long)] yes: bool }`, `Dispute { #[arg(long)] id: String, #[arg(long)] reviewer: String }`, `Supersede { #[arg(long)] id: String, #[arg(long)] new_id: String, #[arg(long)] reviewer: String }`.

    Implement `handle_isnad(action, db_path, json) -> i32` running on a multi-thread tokio runtime, mirroring hadith handler. Inside async:
    - Open SqliteDatabase (read-write pool).
    - Build IsnadReaderService + SqliteIsnadGraphStore + IsnadToolBackend.
    - Dispatch each action to the corresponding backend method, format human output per UI-SPEC copywriting contract:
      - Narrator: `{stable-id} — {primary_name}` header + `variants: {v1}, {v2}, …` + `rijal sources ({N} scholar(s)):` + per-scholar rows `{scholar_name} — {source_citation} — {grading_value or "no grade"} ({decision})`.
      - Rijal: same rijal block.
      - Trace: count/paths summary line + indented edge rows `  {src} -{edge}-> {dst}` with per-link `provenance_layer`, confidence band + ` (uncertain)` suffix, label. Truncated → `… (truncated)` + `incomplete: {reason}`; paths list `unknown (truncated)` when truncated else `no path (complete search)` when empty.
      - Identity verbs: `<verb> <assertion-id> (<decision>) by <reviewer> at <decided-at>[ (supersedes <old-id>)]`.
    - Reject requires `--yes` else print `refusing to reject without --yes` (non-terminal) and exit usage. On success print `<summary> (audit #<seq>)`.
    - Error format: `[QAI-ISNAD-NNNN] <detail>` + `      Remedy: <fix>` + `      Next: qai isnad … --help`.
    - JSON output: serialize the ToolResult/envelope via serde_json, print pretty when --json.
    - Empty states use zero-count lines (`rijal sources for {id}: 0 scholar(s)`, `identity review: 0 pending`), never generic "No data".

    Use `application::quran_cli::CommandOutput` for human/json split, matching hadith/links handlers.
  </action>

    <automated>cargo build -p cli 2>&1 | tail -10  </verify>
