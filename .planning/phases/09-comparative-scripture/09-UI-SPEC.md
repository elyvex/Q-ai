## Color

### Base UI Chrome (60/30/10)

| Role | Light | Dark | Usage |
|------|-------|------|-------|
| Dominant (60%) | `#fafafa` | `#09090b` | Page background, main content |
| Secondary (30%) | `#ffffff` | `#18181b` | Cards, sidebar, nav, popovers |
| Accent (10%) | `#0f766e` | `#14b8a6` | Primary buttons, active nav, links, selected items |
| Destructive | `#dc2626` | `#ef4444` | Destructive actions only |

Accent reserved for: primary CTA buttons, active navigation items, selected tabs, focus rings, links, and the canonical layer badge. Never used for translation or annotation layers.

### Layer Semantic Tokens (hard requirement — preserved from Phase 5)

| Layer | Light FG | Light BG | Dark FG | Dark BG | Usage |
|-------|----------|----------|---------|---------|-------|
| Canonical | `#1b1b1f` | `#ffffff` | `#e5e7eb` | `#0b1020` | Canonical Arabic text — Quran + scripture matn |
| Translation | `#334155` | `#f1f5f9` | `#cbd5e1` | `#1e293b` | Translation text (all languages) |
| Annotation | `#7c2d12` | `#fff7ed` | `#fed7aa` | `#431407` | Computational suggestions, annotations, honest labels |

These three layer tokens are **structural**: canonical text renders only inside `--layer-canonical-*`, translations only inside `--layer-translation-*`, annotations only inside `--layer-annotation-*`. A translation can never receive a canonical token (ADR-0112/D-09). This constraint is enforced by the component type system, not just CSS.

### Semantic Status Colors

| Status | Light | Dark | Usage |
|--------|-------|------|-------|
| Confirmed | `#15803d` | `#22c55e` | Owner-confirmed parallel links |
| Uncertain | `#b45309` | `#f59e0b` | Computational suggestions (always labeled) |
| Rejected | `#dc2626` | `#ef4444` | Rejected suggestions |

## Page Inventory

The full GUI redesign covers these views:

| View | Route | Description |
|------|-------|-------------|
| Reading | `/` and `/read/{slug}@{version}/{surah}:{ayah}` | RTL Arabic reading with layer separation, translation modes, word inspector |
| Research | `/research` | Search across Quran with kind selector (exact/normalized/phrase/concatenated/root/lemma/family/frequency) |
| Comparative Scripture | `/scripture` | Edition browser, parallel-passage research with uncertainty labels, cross-domain filter |
| Graph | `/graph` | Knowledge graph neighbors/paths with edge provenance |
| Hadith & Tafsir | `/hadith` | Hadith records with matn/isnad separation, attributed gradings, tafsir explorer |
| RAG Debug | `/rag-debug` | Retrieval inspection with route decision + checksum |
| Explorer | `/explorer` | API explorer with presets covering every domain |
| Citation | `?citation={id}` | Deep-link citation verification with server-side re-verify |

### Layout Pattern

All views use a **sidebar navigation + main content** shell:
- **Sidebar** (240px, collapsible): NavigationMenu with icons + labels for all views
- **Main content**: Card-based layouts with consistent padding (md/lg)
- **Top bar**: View title + primary CTA + theme toggle

### Reading View Specifics
- **Focal point**: The centered Arabic scripture column is the primary visual anchor — it draws the eye first. All other UI (sidebar, top bar, translation panels) yields visual precedence to this column.
- Single centered column (max-width 72ch) for Arabic scripture
- `dir="rtl"` and `lang="ar"` on scripture container
- Layer separation enforced by component type system (AyahColumn accepts only canonical text)
- Translation modes: inline / side-by-side / side-panel (preserved from Phase 5)
- Word inspector: popover / panel / pin (preserved from Phase 5)

### Comparative Scripture View Specifics
- **Edition browser**: Select for tradition (Jewish/Christian) → edition → book → chapter → verse
- **Parallel passages**: Table showing computational suggestions with confidence band + "Uncertain" badge + confirm/reject actions
- **Domain filter**: Switch toggles for Quran / Hadith / Tafsir / Scripture / Books (default: all)
- **Cross-domain results**: Merged list with domain badge + source + confidence
