    1. Implement atomic UI primitives:
       - `Button`: 5 variants (`primary`, `secondary`, `outline`, `ghost`, `danger`) × 4 sizes (`sm`, `md`, `lg`, `xl`) × 6 states (`default`, `hover` +1px lift, `active` 0.98 scale, `focus` 2px ring with offset, `disabled`, `loading` with spinner).
       - `IconButton`: accessible icon buttons with `aria-label` and tooltip support.
       - `Input`, `TextArea`, `Select`: 8-10px radius, 1px neutral border, subtle focus ring, disabled and invalid states with accessible error text.
       - `Badge` & `Chip`: status indicators with semantic color accents and text labels.
       - `Card`: subtle border, soft elevation, optional hover elevation for clickable cards.
       - `Modal` & `Dialog`: focus-trapped, backdrop blur, ESC dismiss, keyboard accessible.
       - `Tabs` & `Accordion`: accessible tab panels with keyboard navigation (arrows/enter).
       - `Skeleton` & `Spinner`: shimmering loading placeholders with no layout shift.
       - `Toast`: accessible notification container with error/success states.
       - `EmptyState` & `ErrorState`: illustrated/informative fallback blocks with action buttons.
       - `ErrorBoundary`: React error boundary catching render crashes with a reload/report action.
    2. Implement `AnimatedBackground`:
       - Pure CSS animated gradient field positioned behind content (`z-index: -1`, `pointer-events: none`).
       - Opacity $\le 0.15$ so text contrast meets WCAG 2.2 AA.
       - Pauses animation when document is hidden (`document.visibilityState === 'hidden'`) and completely disables motion when `prefers-reduced-motion` is matched.
