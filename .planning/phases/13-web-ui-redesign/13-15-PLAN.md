<objective>
Close the two open gaps in `13-VERIFICATION.md` (status `gaps_found`, 9/11) and retire the token-mirror advisory that produced them.

G-13-1 — make the animated background real. `web/src/components/background/AnimatedBackground.tsx` is implemented and unit-tested but imported nowhere, so roadmap SC2 ("an animated background") fails. Two independent defects hide it: the component is never mounted, and the mount point (`web/src/App.tsx`) wraps the router in an opaque page-ground utility that would paint over an element using `z-index: -1` even after a one-line mount. The component also still paints the superseded teal gradient instead of the shipped Concordance tokens, and sets `animation-play-state` / `animation-duration` without any keyframes behind them — so even when mounted it would be a static wash.

G-13-2 — record motion performance honestly. The committed `web/package.json` carries no Lighthouse, Playwright, or axe package, so no LCP/CLS run was possible when the phase was verified. The working tree does carry an uncommitted devDependency diff (`lighthouse`, `@playwright/test`, `@axe-core/playwright`) with the binaries already present under `web/node_modules/.bin/` — so the measurement is decidable now, without a new install, but whether that dependency diff is kept and committed is the operator's call. The measurement is therefore an operator-gated task kept strictly separate from the code fix: the code ships first, the measurement either runs against recorded budgets or is deferred with a named owner and target phase in `13-MOTION-EVIDENCE.md`.

Advisory — one source of truth for tokens. `web/src/tokens/index.ts` and four sibling CSS mirrors (`colors.css`, `elevation.css`, `typography.css`, `motion.css`) still declare the superseded teal accent, the dark canvas, and stone neutrals; only `web/src/tests/reachability.test.ts` imports them, and `13-VERIFICATION.md` records the disagreement. They are deleted, and the reachability test keeps a design-contract guard over `index.css` / `layers.css` instead.

Purpose: the phase goal and roadmap SC2/SC7 are the authority for this plan. `13-CONTEXT.md` ("Animated Background: None") and `13-UI-SPEC.md` §17 ("no gradient drift") record the earlier decision to drop the field; `13-VERIFICATION.md` treats the roadmap criterion as binding and the orchestrator has chosen to mount rather than amend the roadmap. Both documents therefore receive an append-only dated amendment (Task 2) so the next verifier does not read a spec that contradicts the shipped UI.

Output: a mounted, tokenised, keyframe-driven background with a regression test that fails on unmount; one token source with a drift guard; and a motion-evidence artifact that is either measured or explicitly deferred. No package installs in the autonomous path, no backend change, no third-party network request, light theme only.
