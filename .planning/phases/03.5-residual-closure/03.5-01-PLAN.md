## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| board row → done.md evidence | A status cell becomes a completion claim; it must be backed by a link, not by reading |
| document prose → implementation | A document can drift into describing behavior that does not exist; the reader trusts it |
