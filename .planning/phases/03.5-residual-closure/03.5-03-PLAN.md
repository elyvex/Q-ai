Metrics. Compute, per search mode, the golden-agreement rate, the empty-result rate, and the determinism rate (same input twice yields byte-identical ranked output); and, per lexicon tool, the attribution-completeness rate, the typed-unavailable rate, and the determinism rate. Baseline. `baseline.json` records the current measured value for each metric with an explicit `tolerance` column, and the harness diffs a fresh run against it. A metric outside tolerance fails; a metric inside tolerance passes. The comparison is exact against the declared tolerance, never a fuzzy similarity.

Gating boundary. The harness gates **mechanical** regressions only — an empty result set where goldens exist, a missing attribution block, a determinism failure, a dataset version it cannot resolve. State this in the report output itself so a reader cannot mistake the harness for a linguistic verdict.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| tool output → caller | A published tool crosses into a result a caller may not inspect the internals of |
| metric run → quality verdict | A number crosses into a claim about Arabic linguistics |
| golden row → scholarly authority | A fixture row crosses into something a reader may treat as verified |
| fixture soak → production evidence | Synthetic scale crosses into an implied real-corpus guarantee |
