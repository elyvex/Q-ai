# Definition of Done

A task is done only when all of the following are true:

1. Implementation is complete and committed on a feature branch.
2. Tests exist for the new behavior and all tests pass.
3. Lints, formatting, and type checks pass.
4. The task document under `docs/04-tasks/` reflects the final state.
5. Acceptance criteria in the active phase plan are met.
6. The rollup file `docs/06-progress/task-done-rollup.md` is updated.
7. Follow-ups are recorded in `docs/05-followups/open-questions.md`.
8. `CHANGELOG.md` is updated when the change is user-visible.
