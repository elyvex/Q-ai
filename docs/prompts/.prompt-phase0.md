### Non-Negotiable Rules
1. **`domain` crate depends ONLY on serde, thiserror, time, uuid** — no I/O, no async runtime.
2. **Canonical immutability is a type-level property** — canonical rows written only through `CanonicalWriter` requiring `ApprovalToken`.
3. **No domain crate may depend on** `api`, `server`, `tui`, `cli`, or any concrete provider.
4. **Every derived artifact records the version of everything it was derived from** (§76).
5. **Deny-by-default** — permissions, network, filesystem, side effects default to empty sets.
6. **Nothing that can modify data runs inside `doctor`** (§50).
7. **Migration files are append-only and checksummed** — editing an applied migration causes hard failure (QAI-DB-0003).
8. **Secret sentinel must appear in ZERO output bytes** — logs, errors, CLI output, doctor JSON, audit rows. This is a permanent CI gate.
9. **All writes to projection-relevant state must insert an outbox row in the same transaction** (commit implies outbox, impossible by construction).

### Crate Dependency Rules (enforced by `cargo xtask arch-check`)
